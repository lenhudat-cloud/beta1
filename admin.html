Quản trị bài viết

Viết, sửa, xóa bài trong mục Tin tức. Bài được lưu vào tệp posts.json trên GitHub; trang web tự đọc tệp này.

1. Kết nối GitHub

Cách tạo token
  1. GitHub: Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
  2. Repository access: chọn Only select repositories, chọn repository của bạn.
  3. Permissions > Repository permissions > Contents: Read and write.
  4. Đặt ngày hết hạn ngắn, tạo token, dán vào ô trên. Token chỉ lưu trong tab trình duyệt này và mất khi bạn đóng tab. Không gửi token cho ai.
