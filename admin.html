Quản trị website

Viết bài, hẹn giờ đăng, duyệt bài và chỉnh sửa nội dung, hình ảnh các trang theo quyền của từng tài khoản. Nội dung lưu trên GitHub; trang web tự đọc lại.

1. Kết nối GitHub

Cách tạo token theo quyền
  1. GitHub: Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token. Chọn Only select repositories và chọn repository này. Đặt ngày hết hạn ngắn.
  2. Root và Admin: cấp Contents: Read and write và Issues: Read and write.
  3. Member: chỉ cấp Issues: Read and write, không cấp Contents. Nhờ vậy member không thể đăng thẳng bài lên website, kể cả khi sửa trang này.
  4. Token chỉ lưu trong tab trình duyệt. Không gửi token cho ai.

          Xem trang

          Hướng dẫn nhanh
          • Gõ trực tiếp vào các ô để đổi chữ. Nút Khôi phục mặc định đưa về chữ gốc.
          • Bao chữ trong dấu sao, ví dụ *sáu lĩnh vực*, để in nhấn màu đỏ. Xuống dòng bằng phím Enter.
          • Xóa trống một ô rồi lưu để ẩn mục đó khỏi trang.
          • Ảnh được tự thu nhỏ trước khi tải lên. Ảnh nền nên có chiều ngang từ 1600 px trở lên.
          • Sau khi lưu, trang web cập nhật sau khoảng 1 đến 2 phút.
