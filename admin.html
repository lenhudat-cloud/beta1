Quản trị nội dung website

Chọn một mục menu, viết hoặc sửa nội dung rồi bấm Lưu. Nội dung được lưu thành các tệp .json trên GitHub và trang web tự đọc các tệp này.

1. Kết nối GitHub

Cách tạo token
  1. GitHub: Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
  2. Repository access: chọn Only select repositories, chọn repository của bạn.
  3. Tab Repositories > Contents: Read and write.
  4. Đặt ngày hết hạn ngắn. Token chỉ lưu trong tab trình duyệt này. Không gửi token cho ai.
